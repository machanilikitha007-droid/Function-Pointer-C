# Function Pointer in C

This program demonstrates how a function pointer can store the address
of a function and use it to call that function.

## File

function_pointer.c

## Concepts Used

- Function pointer
- Function definition
- Function call
- Pointer to function

## How to Run

gcc function_pointer.c -o function_pointer
./function_pointer
